# AA Picker — подбор ИИ-моделей под задачу

Локальный подборщик ИИ-моделей на базе рейтингов Artificial Analysis (277 моделей, 518 эндпоинтов провайдеров) с веб-интерфейсом.

## Быстрый старт (Windows)

1. Убедитесь, что установлен **Python 3.10+** (внешние пакеты не нужны, всё работает на стандартной библиотеке).
2. Скачайте репозиторий (`Code` -> `Download ZIP`) и распакуйте, либо выполните `git clone`.
3. Запустите двойным кликом файл `scripts\start_aa_picker.bat`.
4. Браузер откроет страницу `http://127.0.0.1:8742` автоматически.

## Опционально

- Для подбора бенчмарков через Gemini Decision задайте переменную окружения `GEMINI_API_KEY` перед запуском. Без неё подбор работает по встроенным правилам.
- Запуск из консоли (CLI): `python scripts\aa_picker.py "код на Python, дёшево"`
